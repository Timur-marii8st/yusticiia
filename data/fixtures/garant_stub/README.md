# Заглушка ответов ГАРАНТ

Файлы здесь — **предположение о форме ответа по документации API**, а не
записанные ответы сервера. Токен на момент их создания получен не был.

Каждый файл обязан содержать `"assumed": true` — без этой отметки
`StubRedactionSource` его не загрузит.

Когда токен появится: выполнить `SO_REDACTION_SOURCE=garant second-opinion redactions
--topic <идентификатор документа>`, сверить фактическую форму ответа с этими файлами и
заменить их записанными.
