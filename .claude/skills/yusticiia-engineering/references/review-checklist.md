# Проверка собственной правки

Список для того, кто уже написал код и собирается показать его человеку.
Порядок не случаен: сначала то, что делает работу бессмысленной, если
нарушено.

## 1. Правовая сторона

- [ ] Новое правило движка опирается на норму со статусом `verified`?
      Без этого правило не добавляется — И-10 в `docs/TZ.md`.
- [ ] Вывод раскрывается до факта, цитаты, нормы, редакции и источника?
- [ ] Ничего не подставилось «молча»: свежая редакция, срок по умолчанию,
      дата вместо извлечённой?
- [ ] Формулировки описательные там, где речь о статистике? Слова
      «следует», «рекомендуется», «завышен», «занижен» — запрещены и
      проверяются тестом.
- [ ] Неопределённость показана, а не скрыта? UNKNOWN с объяснением
      лучше, чем догадка.

## 2. Данные

- [ ] Синтетическое помечено `synthetic: true`, предположение —
      `assumed: true`?
- [ ] Корпус норм опечатан после правки (`second-opinion norms-seal`)?
- [ ] Персональные данные не попали в новое место: в лог, в журнал, в
      выгрузку, во внешний запрос?

## 3. Код

- [ ] `ruff check .` чисто.
- [ ] `mypy` чисто. Если ошибка в обработчике FastAPI — см. ловушку 6,
      переписывать обработчик не нужно.
- [ ] `pytest --cov` зелёный, **и число пропущенных тестов осмотрено**:
      без `SO_TEST_DATABASE_URL` шестнадцать тестов уходят в skip.
- [ ] Новый эндпойнт описан в `docs/API.md` (иначе упадёт тест).
- [ ] Ответ-файл описан в `responses` (иначе упадёт тест схемы).
- [ ] Новый инструмент, создающий файлы, добавлен в `.gitignore`.
- [ ] Перехват целого класса ответов (обработчик исключений,
      middleware) сохраняет то, что этот класс нёс раньше: заголовки,
      коды, тело. Проверяется чужими тестами — прогоняйте весь набор,
      а не только свой файл.

## 4. Интерфейс

- [ ] Поднята метка `?v=` у `app.js` и `style.css`.
- [ ] Сервер перезапущен перед проверкой в браузере.
- [ ] Проверено в браузере, а не только тестами: открыть страницу,
      выполнить сценарий, посмотреть глазами.
- [ ] Новое поле формы имеет подпись (`<label>` или `aria-label`);
      плейсхолдер подписью не считается.
- [ ] Новая секция имеет доступное имя, заголовок — уровня `h2`.
- [ ] Сообщение об ошибке появляется рядом с действием, а не в другом
      конце страницы.
- [ ] Запрос к API идёт через `apiFetch`, а не обычной ссылкой: ссылка
      уходит мимо авторизации.

## 5. Документация

- [ ] `docs/TZ.md`: статус требования изменён, если он изменился.
- [ ] `docs/IMPLEMENTATION_STATUS.md`: новая запись сверху.
- [ ] `CHANGELOG.md`: что сделано и **почему именно так**.
- [ ] Решение с последствиями — ADR в `docs/ADR/`.
- [ ] Числа в документации совпадают с измеренными, а не с ожидаемыми.

## 6. Честность отчёта человеку

- [ ] Сказано, что проверено, а что нет.
- [ ] Найденная по ходу ошибка названа, а не тихо исправлена.
- [ ] Если что-то не получилось — сказано прямо, без «в целом работает».
