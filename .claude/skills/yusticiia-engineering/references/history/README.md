# Архив: статусы и дорожная карта

Материалы, которые вели разработку и перестали быть нужны читателю
репозитория. Лежат здесь, чтобы их можно было поднять в споре о том,
что и когда было сделано, — но не мозолили глаза тому, кто разбирается
в самой системе.

| Файл | Что это | До какого момента вёлся |
|---|---|---|
| `implementation-status.md` | Помесячный статус реализации: что закрыто в каждой итерации, какие ограничения известны. Дублировал `CHANGELOG.md`, только подробнее и с расхождениями | 2026-09-19, итерация 0.54 |
| `roadmap-m0-m10.md` | Дорожная карта по майлстоунам M0–M10 с критериями приёмки. Выполнена; на смену пришли очереди работ в `docs/TZ.md`, раздел 7 | 2026-09 |

Числа и утверждения в этих файлах верны **на момент записи**. Сверять их
с сегодняшним кодом бессмысленно: для этого есть `docs/TZ.md` (раздел 6 —
измеренное состояние) и `CHANGELOG.md`.
