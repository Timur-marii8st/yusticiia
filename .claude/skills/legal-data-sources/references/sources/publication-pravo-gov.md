# publication.pravo.gov.ru — официальное опубликование

Официальный интернет-портал правовой информации в части **опубликования**
актов. Это **другая система**, чем ИПС `pravo.gov.ru/proxy/ips/`, и
путать их — источник главного заблуждения про OCR.

## Что даёт

- Ленту новых публикаций: акт, его номер, дата, издавший орган.
- API документов: `publication.pravo.gov.ru/api/Documents` и
  `/api/Document` — карточки и метаданные в JSON.
- Сам текст акта — **в PDF**, часто сканом без текстового слоя.

## Ключевое различие с ИПС

| | publication.pravo.gov.ru | pravo.gov.ru/proxy/ips/ |
|---|---|---|
| что публикует | акты по мере принятия | консолидированные редакции |
| формат текста | PDF, часто скан | HTML |
| годится для | обнаружения новых актов | получения текста нормы |
| нужен ли OCR | да, для сканов | нет |

Отсюда вывод, который экономит месяцы: обнаруживать изменения по ленте
публикаций, а **текст брать из ИПС**, оставляя PDF как официальный
контрольный оригинал для выборочной сверки.

Вместо «149 новых документов → 149 распознаваний» получается «149 новых
публикаций → найти их текстовые версии → 145 получить текстом → 4
отправить в OCR».

## Про OCR

Для норм распознавание — не узкое место. В корпусе хранится не текст
закона целиком, а выверенное изложение с привязкой к первоисточнику:

```
text:      «Ч. 1 ст. 158 УК РФ в редакции 1996–2003 (сверено 03.09.2026):
            лишение свободы на срок до трех лет (36 мес.).»
sanctions: [{punishment_type: imprisonment, max_months: 36}]
```

`max_months: 36` не извлекается из PDF никаким распознаванием — это вывод
юриста из текста санкции. Идеальный OCR даст текст статьи и ни одной
структурной санкции.

**Отдельная опасность.** В праве ошибка распознавания в числе меняет
смысл: «до трёх лет» против «до трети», «36» против «86». Поэтому любой
машинно извлечённый текст обязан оставаться `draft` до юридической сверки.

Порядок предпочтений при получении текста:

1. HTML-источник (ИПС, ГАРАНТ) — распознавание не нужно;
2. текстовый слой PDF (`pypdf`) — работает на большинстве официальных
   публикаций, но приносит переносы, колонтитулы и сноски вперемешку;
3. локальный OCR (`tesseract` + `rus`) — закрывает сканы, данные не
   покидают контур;
4. внешний OCR-сервис (Yandex Vision, ABBYY) — качество выше, но документ
   уходит во внешний контур. Для публичных норм допустимо, для судебных
   актов — нет. На объёме в десятки статей не нужен вовсе.
