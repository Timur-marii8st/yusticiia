# PRIVACY

Обращение с персональными данными (ПДн) и чувствительной информацией
судебных документов.

## Категории данных в системе

| Данные | Где обрабатываются | Куда передаются |
|---|---|---|
| Текст загруженного документа | память процесса, `data/store/documents/` | никуда (дефолт) |
| Извлечённые факты и отчёты | память процесса, `data/store/analyses/` | никуда (дефолт) |
| Хэши SHA-256, версии правил/промптов | `data/store/audit.jsonl` | никуда |
| Запросы поиска норм | память процесса | никуда |

## Режимы обработки

1. **Офлайн (по умолчанию).** LLM-провайдер — `mock`; внешние сетевые
   вызовы из конвейера анализа отсутствуют. Реальные судебные документы
   покидают машину только вместе с её носителем.
2. **Внешний LLM (`SO_LLM_PROVIDER=openai_compatible`).** Текст документа
   (первые 20 000 символов) отправляется на указанный
   `SO_OPENAI_BASE_URL`. Это осознанное решение оператора; для реальных
   дел допускается только:
   - в закрытом контуре (локальная/корпоративная модель за
     OpenAI-совместимым API), либо
   - после юридического разрешения передачи ПДн соответствующему провайдеру
     и обезличивания документов.

Ответственность за включение режима и выбор контура лежит на операторе;
система не переключает режимы сама.

## Хранение и удаление

- Всё локально: `SO_DATA_DIR` (по умолчанию `./data`).
- Удаление через API (право на забвение): `DELETE /api/documents/{id}`
  удаляет документ и **все отчёты по нему** (каскад);
  `DELETE /api/analyses/{id}` — отдельный отчёт. Обе операции фиксируются
  в аудит-журнале без текстов.
- Альтернатива: удалить JSON-файлы из `data/store/{documents,analyses}/`
  вручную; аудит-журнал содержит только хэши.
- Резервные копии каталога `data/` следует защищать как конфиденциальные.

## Минимизация

- В аудит-журнал и логи тексты не пишутся (см. docs/SECURITY.md п. 4, 7).
- LLM-экстрактор ограничивает объём передаваемого текста
  (`MAX_DOCUMENT_CHARS = 20000`).

## Обязанности оператора

1. Загружать документы, обработка которых разрешена регламентом суда.
2. Не включать внешний LLM-контур без правового основания.
3. Ограничивать доступ к каталогу `data/` средствами ОС.
4. При демонстрациях использовать только синтетические фикстуры или
   обезличенные образцы (в репозитории все данные синтетические и явно
   помечены).
