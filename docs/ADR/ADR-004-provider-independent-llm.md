# ADR-004: Провайдеро-независимый LLM-слой

- Статус: принят (2026-08-25)

## Контекст

Бизнес-логика не должна зависеть от конкретного вендора (OpenAI, YandexGPT,
GigaChat, локальные модели). Возможен закрытый контур без интернета.

## Решение

Интерфейс `LLMProvider`: `generate_structured(prompt_name, input, schema)`,
`generate_text(...)`, `embed(...)`. Адаптеры: `MockLLMProvider`
(детерминированные ответы для тестов и офлайн-запуска, включён по умолчанию)
и `OpenAICompatibleProvider` (любой OpenAI-совместимый endpoint). Выбор —
переменной окружения `SO_LLM_PROVIDER`; ключи — только из окружения.

Каждый реальный вызов логируется в audit trail с именем провайдера, моделью
и версией промпта. Промпты централизованы в `prompts/` и версионируются.

## Альтернативы

- **Прямые вызовы SDK вендора в коде:** жёсткая привязка, утечка секретов,
  невозможность закрытого контура. Отклонено.
- **Только локальные модели:** лишает гибкости; моки закрывают офлайн-нужды.

## Последствия

+ переносимость, тестируемость без сети, аудит вызовов;
− каждый адаптер требует собственной проверки формата ответов
(решается схемной валидацией и тестами на мок-провайдере).
