# ADR-001: Гибридный Rule Engine + LLM вместо LLM-only

- Статус: принят (2026-08-25)
- Связи: ADR-004, ADR-005

## Контекст

Проверки Общей части УК (пределы наказания при покушении, особом порядке,
смягчающих обстоятельствах) формализуемы. Нужно решить, чем их выполнять.

## Решение

Детерминированный Rule Engine на Python-классах с декларативными
метаданными; версии правил фиксируются в `RuleEvaluation`. LLM используется
только для извлечения фактов и пояснений, никогда — для юридической оценки.

## Альтернативы

- **LLM-only (RAG + чат):** чёрный ящик, нет гарантий, нет прослеживаемости;
  нарушает требования конкурса о прозрачности. Отклонено.
- **Внешний движок правил (Drools/Prolog):** дополнительная среда исполнения
  и слабая типизация связи с доменными моделями. Отклонено для MVP.
- **Самописный DSL:** преждевременная абстракция; правила читаемы и как код.

## Последствия

+ 100% воспроизводимость и регрессионные тесты; + полная трассируемость;
− придётся вручную кодировать каждую проверку (принимаем: качество важнее
покрытия на старте).
