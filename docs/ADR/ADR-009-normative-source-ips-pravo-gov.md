# ADR-009: Источник редакционной истории — ИПС pravo.gov.ru; RusLawOD отклонён

- Статус: принят (2026-09-14)

## Контекст

Движок правил сравнивает срок из проекта акта с пределами санкции той
редакции нормы, которая действовала на юридически значимую дату. Значит
нужен источник, отдающий **историю редакций**, а не только действующий
текст. Аудит покрытия показывал 15 норм из 27, у которых история не
зафиксирована вовсе.

Рассматривались четыре пути.

**RusLawOD** — открытый корпус российского законодательства. Отклонён:
авторы прямо пишут, что корпус содержит только **исходные** редакции, без
консолидированных, и что он не является официальным изданием. Для нашей
задачи это негодный источник: по исходной редакции 1996 года нельзя
проверить приговор 2024 года.

**Russian-Law-MCP** — предлагался как быстрый baseline. Репозиторий по
названию отдаёт 404; вероятный настоящий независимо не подтверждён, а
исторические редакции у него в планах, а не в продукте. Не рассматривается
до появления редакций.

**ГАРАНТ API** — `GET /v2/redactions/$topic` отдаёт периоды действия,
изменяющие документы и явные периоды неопределённости. Доступ только по
OAuth-токену, который выдаёт обслуживающая организация по заявке; токена
нет, сроки неизвестны, лицензионные условия для конкурсной работы не
выяснены.

**ИПС «Законодательство России»** (`pravo.gov.ru/proxy/ips/`) —
государственная система. Проверена 14.09.2026 на документе 102041891
(УК РФ): 366 редакций, у каждой указан изменяющий закон и его дата,
подготовленные редакции отдают полный консолидированный текст.

## Решение

Основной источник — **ИПС pravo.gov.ru** (`SO_REDACTION_SOURCE=pravo`,
реализация `legal_sources/pravo_gov.py`). Он государственный, не требует
токена и подписки, и снимает лицензионный вопрос целиком.

**Собственный движок применения поправок не пишется.** Источник отдаёт
готовые консолидированные редакции — собирать их из текстов поправок не
нужно. Это решение принято по факту проверки, а не из осторожности.

ГАРАНТ остаётся вторым провайдером за тем же интерфейсом
`RedactionSource`: он отдаёт периоды действия редакций вместо дат актов,
то есть снимает главную оговорку ИПС. Включается сменой переменной
окружения в день получения токена.

RusLawOD не используется. Решение фиксируется здесь, чтобы разбор не
повторялся.

## Ограничения источника

Скрывать их запрещено принципами проекта, поэтому они отражены в выдаче:

- **дата в списке редакций — дата изменяющего акта, а не дата вступления
  редакции в силу.** Границы редакций отсюда попадают в фикстуру только
  после юридической сверки;
- **153 редакции из 366 помечены «не готова»** — консолидированный текст
  не подготовлен и недоступен; такие редакции уходят в `uncertain`, а не
  выпадают из выдачи молча;
- **`norms-check-amendments` сравнивает крайние редакции** — изменение с
  последующим возвратом к прежней формулировке этим способом не видно.

Поэтому машинный вывод остаётся черновиком: норма считается сверенной
только после `norms-confirm-history`, которую выполняет юрист.

## Альтернативы

- **Ждать токен ГАРАНТ:** ноль риска впустую написанного кода, но и ноль
  движения; при получении токена за неделю до сдачи интеграции не будет.
  Отклонено.
- **Ручной сбор по КонсультантПлюс:** даёт настоящие данные и не зависит
  ни от кого, но для 27 норм это недели работы юриста. Остаётся запасным
  путём и способом подтверждения машинного черновика.
- **Свой движок применения поправок:** месяцы работы и высокий риск
  ошибки в праве. Снят с повестки проверкой ИПС.

## Последствия

+ редакционная история берётся из официального государственного источника,
  без токена, подписки и лицензионных вопросов;
+ критический путь проекта больше не проходит через внешнюю заявку;
+ утверждение «норма не менялась» стало проверяемым одной командой;
− дата вступления редакции в силу требует ручной сверки;
− 153 редакции УК РФ в ИПС недоступны; там, где нужна именно такая
  редакция, потребуется ГАРАНТ или КонсультантПлюс;
− разбор HTML зависит от разметки ИПС: изменение вёрстки ломает клиент,
  поэтому отсутствие списка редакций — явная ошибка, а не пустой результат.
