# ADR-005: Provenance-first модель данных

- Статус: принят (2026-08-25)

## Контекст

Главный вопрос к системе: «Почему система это утверждает?» Ответ должен
строиться из данных, а не из текста отчёта.

## Решение

Provenance встраивается в саму модель:

- `LegalFact.evidence[]` обязателен; факт без доказательств не может иметь
  статус `VERIFIED` (инвариант проверяется валидатором и тестом);
- `Evidence` хранит оффсеты в исходном тексте — цитату можно всегда показать
  в контексте;
- `RuleEvaluation` ссылается на конкретные `facts_used[]` и
  `norms_used[]` (с `version_id` редакции нормы);
- норма ссылается на источник с `retrieved_at` и SHA-256.

Каждый слой добавляет звено цепочки, не разрушая предыдущие.

## Альтернативы

- **Добавить прослеживаемость позже:** потребует миграции всех данных и
  переписывания выводов; дешевле заложить сразу. Отклонено.
- **Хранить ссылки как свободный текст:** не проверяемо автоматически.
  Отклонено.

## Последствия

+ автоматические тесты полноты доказательств; доверие жюри/судов;
− более строгие модели и чуть больше кода извлечения (принимаем).
