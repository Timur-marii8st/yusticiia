# ADR-003: Гибридный поиск дел — структурные фильтры первыми

- Статус: принят (2026-08-25); эмбеддинги отложены до M6

## Контекст

Похожие дела нельзя искать одним лишь косинусным сходством текстов:
юридически значимая близость определяется структурой (статья, часть, стадия,
рецидив, процедура).

## Решение

Конвейер: структурные фильтры → ранжирование. Для MVP ранжирование
лексическое/взвешенное по совпадению признаков; эмбеддинги и реранкинг
добавляются позже поверх тех же фильтров (интерфейс `CaseRetriever`
стабилен). Каждое найденное дело сопровождается `reasons[]` — по каким
признакам оно отобрано.

## Альтернативы

- **Только эмбеддинги:** риск «похожесть 92% ⇒ такое же наказание» —
  псевдоюридический вывод без основания. Отклонено.
- **Только точное совпадение признаков:** упускает содержательную близость.
  Отклонено как единственный механизм.

## Последствия

+ прозрачность отбора, защита от ложной уверенности;
− на старте нет семантической составляющей (принято: см. план M6).
