# ADR-003: Гибридный поиск — структурные фильтры первыми, семантика поверх

- Статус: принят (2026-08-25); обновлён (2026-08-26): семантический
  реранкинг поиска по источникам реализован как опциональный режим

## Контекст

Похожие дела нельзя искать одним лишь косинусным сходством текстов:
юридически значимая близость определяется структурой (статья, часть, стадия,
рецидив, процедура).

## Решение

Конвейер: структурные фильтры → ранжирование. Для MVP ранжирование
лексическое/взвешенное по совпадению признаков; эмбеддинги и реранкинг
добавляются позже поверх тех же фильтров (интерфейс `CaseRetriever`
стабилен). Каждое найденное дело сопровождается `reasons[]` — по каким
признакам оно отобрано.

## Обновление 2026-08-26: семантический реранкинг для поиска источников

Реализован опциональный гибридный режим поиска **по базе норм**
(`SO_RAG_MODE=hybrid`): лексические кандидаты переупорядочиваются
Reciprocal Rank Fusion лексического и семантического ранжирований.
Семантика — детерминированный офлайн `HashingTfidfEmbedder` (символьные
n-граммы + слова → хэш-вектор), внешний провайдер `/embeddings` — только
явно. Реранкинг меняет порядок найденных кандидатов и не добавляет новых
фрагментов.

**Эмпирика на корпусе фикстур:** lexical MRR 0.958 / nDCG@10 0.969 против
hybrid 0.896 / 0.922 при равном Recall@5 = 1.0. Дефолт остаётся `lexical`;
переключение на `hybrid` — по метрикам после роста корпуса и появления
перефразированных запросов. Для сопоставимых дел семантическое сходство по-
прежнему не используется как основание отбора.

## Альтернативы

- **Только эмбеддинги:** риск «похожесть 92% ⇒ такое же наказание» —
  псевдоюридический вывод без основания. Отклонено.
- **Только точное совпадение признаков:** упускает содержательную близость.
  Отклонено как единственный механизм.

## Последствия

+ прозрачность отбора, защита от ложной уверенности;
+ слой векторизации изолирован за `EmbeddingProvider`, режим измеряется
  в `make eval` обоими способами;
− на старте нет семантики в отборе дел (принято: см. ROADMAP);
− hybrid на малом корпусе уступает lexical (измерено, зафиксировано).
