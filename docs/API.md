# API

Базовый адрес: `http://127.0.0.1:8000` (loopback; собственной
аутентификации нет — см. docs/SECURITY.md п. 6). Все ответы — JSON.
Интерактивная спецификация: `/docs` (Swagger UI, генерируется FastAPI).

## Документы

| Метод и путь | Назначение | Коды |
|---|---|---|
| `POST /api/documents` | создать документ из текста `{filename, text}` | 200; 400 — пусто/неподдерживаемый формат/превышен лимит |
| `POST /api/documents/upload` | загрузить файл (multipart, поле `file`); TXT/MD/DOCX/PDF с текстовым слоем | 200; 400 |
| `GET /api/documents/{id}` | текст документа + SHA-256 | 200; 404 |
| `DELETE /api/documents/{id}` | удалить документ **и все отчёты по нему** (каскад) | 200; 404 |

## Анализ

| Метод и путь | Назначение | Коды |
|---|---|---|
| `POST /api/documents/{id}/analyze` | полный конвейер: факты → проверки → практика → аналитика. Тело (необязательно): `{"applicable_at": "ГГГГ-ММ-ДД"}` — юридически значимая дата для выбора редакции норм | 200; 404 |
| `GET /api/analyses/{id}` | отчёт анализа целиком | 200; 404 |
| `DELETE /api/analyses/{id}` | удалить отчёт | 200; 404 |

## Человек в контуре

| Метод и путь | Назначение | Коды |
|---|---|---|
| `PATCH /api/analyses/{aid}/facts/{fid}` | подтвердить факт (`{"status":"VERIFIED"}`), исключить (`"NOT_FOUND"`) или исправить значение (`{"value": …}`); отчёт пересчитывается детерминированно | 200; 400 (недопустимый статус/значение, VERIFIED без цитаты); 404 |
| `POST /api/analyses/{aid}/facts` | добавить обстоятельство «с нуля»: `{"type", "value", "quote"}`. Цитата обязана дословно находиться в документе | 200; 400 (цитата не найдена, неизвестный тип, значение не по схеме); 404 |

## Нормы и источники

| Метод и путь | Назначение | Коды |
|---|---|---|
| `GET /api/norms` | список норм базы | 200 |
| `GET /api/norms/{norm_id}?applicable_at=…` | норма со всеми редакциями либо конкретной редакцией на дату | 200; 400 (неверная дата); 404 |
| `GET /api/search?q=…&limit=&code=&article=&applicable_at=` | лексический (или гибридный, см. ADR-003) поиск по базе источников; каждый результат — фрагмент реально хранящейся редакции с реквизитами и SHA-256 | 200 |

## Инварианты (действуют на всех эндпоинтах)

1. Ни один юридически значимый результат не существует без provenance:
   факт → цитата с оффсетами → правило/норма → редакция → источник.
2. Поиск возвращает только реально хранящиеся фрагменты; пустой результат
   честнее выдуманного ответа.
3. Текст документа — недоверенные данные (prompt injection не меняет
   поведение системы).
4. Статистика по делам — только описательная.
