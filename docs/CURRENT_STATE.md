## Отклонения от исходного задания и их причины

| Задание | Решение | Причина |
|---|---|---|
| Python 3.12+ | Python **3.11+** (`requires-python = ">=3.11"`) | В целевом окружении установлен Python 3.11.9; код не использует возможности 3.12 |
| PostgreSQL + pgvector | MVP: JSON/SQLite-файловые репозитории за интерфейсами; целевой стек — PostgreSQL | Правило «не переусложняй»: вертикальный срез не требует СУБД; интерфейсы репозиториев делают миграцию безболезненной (ADR-006) |
| React/Next.js | MVP: статическая страница, раздаваемая backend'ом | Для первого среза сборка фронта не нужна; путь миграции на React зафиксирован (ADR-007) |

## Риски, выявленные при аудите

1. **Юридическая достоверность фикстур.** Санкции статей и тексты норм в `data/fixtures/` помечаются `verification_status: draft` и требуют сверки с официальным источником перед любой демонстрацией.
2. **Синтетические данные.** Все тестовые дела — синтетические; они явно маркируются и не должны выдаваться за реальную практику.
3. **Отсутствие размеченного корпуса приговоров** — метрики извлечения пока считаются на крошечном evaluation-наборе; расширение — отдельный майлстоун.
