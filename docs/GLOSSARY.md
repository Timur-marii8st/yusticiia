# GLOSSARY

Термины проекта. Юридические термины даны в рабочем значении для
инженеров; они не заменяют официальные определения.

| Термин | Значение в проекте |
|---|---|
| **Второе мнение** | проверяемый аналитический отчёт по проекту судебного акта: обстоятельства → проверки → нормы → практика; не решение по делу |
| **Document** | нормализованное представление загруженного файла: текст + SHA-256 + оффсеты страниц |
| **Evidence** | доказательство факта: дословная цитата с оффсетами в исходном документе |
| **LegalFact** | юридически значимое обстоятельство (например, «особый порядок»), несущее evidence, статус и способ извлечения |
| **FactStatus** | `VERIFIED` (подтверждено цитатой/человеком) · `LIKELY` (извлечено LLM, требует подтверждения) · `UNCERTAIN` · `NOT_FOUND` · `CONFLICT` |
| **CaseFacts** | сводная модель дела: квалификация, стадия, процессуальные признаки, смягчающие/отягчающие |
| **LegalNorm / NormVersion** | норма права (статья/часть) и её редакция с периодом действия и реквизитами источника |
| **applicable_at** | юридически значимая дата дела; по ней выбирается редакция нормы |
| **LegalRule / RuleEvaluation** | детерминированная проверка и её результат (`PASS/WARNING/FAIL/UNKNOWN`) со списком использованных фактов и норм |
| **Rule Engine** | детерминированный движок формализованных проверок; LLM не используется |
| **ComparableCase / CaseMatch** | синтетическое сопоставимое дело и результат его отбора с объяснением (`reasons[]`, без «процентов сходства») |
| **Analytics** | описательная статистика выборки (медиана, перцентили, распределения); только дескриптивная, не предписывающая |
| **Provenance** | цепочка обоснования: вывод → факт → цитата → правило → норма → редакция → источник |
| **Audit trail** | JSONL-журнал операций с хэшами входа/выхода и версиями правил/промптов/модели; без текстов документов |
| **LLMProvider** | абстракция над LLM (`mock` по умолчанию, `openai_compatible` — явно); бизнес-логика от провайдера не зависит |
| **Prompt injection** | попытка передать модели инструкции через содержимое документа; документ считается недоверенными данными |
| **Human-in-the-loop** | обязательное подтверждение/исправление извлечённых фактов судьёй до использования в выводах |
| **unsupported_claim_rate** | доля VERIFIED-фактов без доказательств; целевое значение 0 |
| **Recall@K / MRR / nDCG** | метрики качества поиска по базе источников (docs/EVALUATION.md) |
| **ADR** | Architecture Decision Record — зафиксированное архитектурное решение (docs/ADR/) |
